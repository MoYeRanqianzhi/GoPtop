## 规则（现行，2026-09-13 二次修订）

- 多代理**允许**（2026-09-13 用户解除禁令），但**账号有并发量限制**：实际并发扇出会被拒（"user concurrency limit exceeded"）。**派发策略：一个一个串行发**（或最多 ≤2 且失败即降串行）。

- 读-only 审查类任务按维度拆分串行执行，产出带 file:line 证据的发现清单，主代理核实后落报告。
- 若再次出现 API 过载/并发拒绝，直接降为单代理串行并先报告用户。
