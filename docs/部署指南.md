# GoPtop 部署指南

> 面向部署者。原理与玩法见 `README.md` 与 `docs/使用指南.md`。

GoPtop 前端是纯静态产物（Vite 构建），任何静态托管都可运行。**信令服务器是可选的**：不部署任何后端也能玩（设置页选「无服务器」，纯直连模式）；要在线名册、跨设备免回执链接与直连失败时的加密兜底中转，可用官方服务器或按第 6 章自建一台。

## 1. 构建

```bash
npm --prefix frontend install
npm --prefix frontend run build    # 产物在 frontend/dist/
```

产物校验清单：

- `frontend/dist/index.html` 存在；
- `frontend/dist/_redirects` 存在且内容为 `/*    /index.html   200`（SPA 回退，构建时自动从 `frontend/public/` 拷入）。

本地预览：`npm --prefix frontend run preview`（只读预览构建产物；跨设备 WebRTC 需 HTTPS，localhost 除外）。

## 2. Cloudflare Pages（推荐）

1. 把仓库推到 GitHub / GitLab。
2. Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**，选本仓库。
3. 构建设置：

| 项 | 值 |
|---|---|
| Framework preset | `Vite`（或 None 自填） |
| Build command | `npm --prefix frontend install && npm --prefix frontend run build` |
| Build output directory | `frontend/dist` |
| Root directory | 留空（仓库根） |
| 环境变量 | 无需任何变量 |

4. 点 Deploy，得到 `https://<项目名>.pages.dev`。此后每次 push 自动重建。

**部署后必验**：

- 直访 `https://<域名>/local` 应显示棋盘而非 404（验证 `_redirects` 生效）；
- 直访 `https://<域名>/p2p` 应显示对战大厅。

## 3. 其他静态托管

| 平台 | 要点 |
|---|---|
| Netlify | `_redirects` 原生支持，构建命令/输出目录同上 |
| Vercel | 不认 `_redirects`，需在 `vercel.json` 加 `rewrites: [{ "source": "/(.*)", "destination": "/index.html" }]` |
| Nginx | `try_files $uri /index.html;` + HTTPS 证书 |

## 4. 为什么必须 HTTPS

跨设备 WebRTC（`RTCPeerConnection`）只在**安全上下文**可用：HTTPS 或 `localhost`。Cloudflare Pages / Netlify / Vercel 默认全站 HTTPS，无需额外配置。

## 5. 部署域名与分享链接的关系

- **Web 用户**：分享链接自动使用「当前访问的站点」，无需任何配置。换域名 = 换个网址访问，链接自然跟着变。
- **Tauri 桌面用户**：桌面壳没有自己的网址，其分享链接指向代码常量 `SHARE_ORIGIN_NATIVE`（`frontend/src/net/links.ts`，默认 `https://goptop.pages.dev`）。**若你部署到自己的域名，请把这处常量改成你的站点**，让桌面用户的分享链接指向你的部署。

除此之外没有任何环境变量或构建参数。信令服务器按需自建，见下一章。

## 6. 自建信令服务器（可选）

服务器是一个 Rust 单二进制（crates/goptop-server），只做「名册 + 信令转发 + 数据兜底中转」，不落地任何数据。运行：

```bash
cargo run -p goptop-server -- --listen=0.0.0.0:9527    # 默认 127.0.0.1:9527
```

- WebSocket 路径为 `/ws`（`wss://你的域名/ws`），前面必须做 TLS 反代（跨设备 WebRTC 要求 HTTPS 页面，页面只能连 wss）：
  - openresty/nginx：`location /ws { proxy_pass http://127.0.0.1:9527; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }`
  - caddy：`goptop.example.com { reverse_proxy /ws 127.0.0.1:9527 }`（自动签发证书）
- 用户在设置页「信令服务器」→ 添加服务器，填 `wss://你的域名/ws` 即可切换。
- 限速与超时为内置（详见 `crates/goptop-server/src/main.rs` 头注释）：hello 10 秒超时；每连接 10 秒窗口最多 500 条；signal payload ≤128 键、relay ≤64 键；60 秒空闲断开。
- 注意：客户端一次只连一台服务器，**不同服务器之间无法互连对战**。
